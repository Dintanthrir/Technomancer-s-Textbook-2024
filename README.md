The Technomancer's Textbook is a cyberpunk setting for Dungeons and Dragons 5e written by Mogrit and available on [Discord](https://discord.gg/YkdhDNvZVy).

This repository contains the text of the book, formatted as markdown.

The 2024 branch contains updates to the book to adapt it to use the 2024 5th Edition rules. You can compare both versions [here](https://github.com/Dintanthrir/Technomancer-s-Textbook-2024/compare/2024)
