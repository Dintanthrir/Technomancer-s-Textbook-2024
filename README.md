The Technomancer's Textbook is a cyberpunk setting for Dungeons and Dragons 5e written by Mogrit and available on [Discord](https://discord.gg/YkdhDNvZVy).

This repository contains the text of the book, formatted as markdown. You can find the text of the most recently published version in the [1.5-Final](https://github.com/Dintanthrir/Technomancer-s-Textbook-2024/tree/1.5-Final) tag.

The main branch contains updates to the book to adapt it to use the 2024 5th Edition rules. You can compare both versions [here](https://github.com/Dintanthrir/Technomancer-s-Textbook-2024/compare/1.5-Final...main)
